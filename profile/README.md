# ✨ SparkoCam

SparkoCam is a **virtual webcam** aimed at streaming. It applies **effects** and **filters**, supports **overlays**, and exposes the transformed feed as a camera for broadcasting and meeting apps.

## 🚀 Why Choose SparkoCam?

The tool separates effects from capture, so the feed is transformed before the broadcasting app receives it. That keeps the look consistent across platforms.

Presets store a filter chain for quick recall.

## 🧩 Quick Start

1. Install SparkoCam and select the camera.
2. Add an effect and an overlay.
3. Adjust color and blur.
4. Choose SparkoCam in your streaming app.
